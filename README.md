# 墨知 MoRead · iOS

面向 iPhone 和 iPad 的本地阅读器，基于 [MoRead](https://github.com/ovo066/MoRead) 的功能与数据规则移植。

当前为开发中的版本，最低支持 iOS 17。

- TXT、EPUB 导入，章节目录、书内搜索、书签与阅读进度保存。
- TXT 导入前预览正文和目录，可选文字编码、内置或自定义章节规则。
- 多级分组、合集和彩色标签，组合筛选、拖动排序与批量归类。
- TXT 上下滚动，以及仿真、覆盖、滑动、无动画四种分页方式；支持跨章翻页和书签返回。
- 字号、行距、纸张配色，以及荧光、下划线和波浪线批注。字号支持滑动和逐格调整，横竖屏切换后保留原文位置。
- 系统、内置 Noto Serif SC 中文衬线、无衬线与等宽字体，字重、字距、首行缩进、段后距和两端对齐；TXT 支持四边独立留白，EPUB 可选择保留原书排版或统一正文样式。
- TTF、OTF、TTC 正文字体库，导入后预览、重命名与切换，字体文件随完整备份恢复。
- 沉浸阅读隐藏状态栏与工具栏，轻点正文中间恢复；EPUB 支持左右翻页、上下滚动。
- 自选应用主题色、阅读背景与正文颜色；照片背景支持浓度调整，图片随完整备份保存。
- 系统连续听书、当前文字高亮、锁屏播放控制，声音搜索与试听，保存语速和音调。
- OpenAI 兼容、MiniMax 和 GMI 云端听书，连续播放、按声音参数复用本机音频及缓存空间管理。
- 按播放分钟数或自然读完章节数的睡眠定时，暂停时暂停计时，支持章节切换和章内定位。
- 自填服务商地址、模型与密钥，支持 OpenAI 兼容、Responses、Claude、Gemini 四种聊天接口。
- SillyTavern JSON、PNG 角色卡与独立世界书 JSON 导入，世界书条目编辑、关键词触发与启用控制，照片头像更换。
- 流式伴读、对话分支、原文引用和已读范围限制。
- 伴读主动查询目录、进度、已读原文、批注、笔记与角色记忆，支持多轮查询、按角色选择工具、停止和查询记录保存。
- 角色原文批注、独立 Markdown 笔记和滚动剧情梗概；按作者保护更新，手动编辑后防止角色覆盖，支持筛选、搜索、分享与完整备份。
- 用户身份切换：自定扮演名称与设定，聊天保留发送时的身份，重新生成沿用原消息身份；角色卡中的 `{{user}}` 使用当前称呼。
- 角色长期记忆：自动提炼、合并与按意思回忆，按角色、扮演身份和书籍保存；支持查看、编辑、遗忘、用户画像及更换模型后重建向量。
- 长对话前情提要：独立选择整理服务商、后台增量整理、查看与清除；编辑消息后核对提要来源，原始聊天记录保留。
- 读完一章后自动随读段评，支持独立服务商、多角色、每章与每日额度；引文逐字校验，标注评论角色并保存处理进度。
- 按书开启向量原文记忆，已读章节断点续传，按意思检索并核对原文位置。
- 已读原文的中文词项与英文单词检索，结合向量排名、精确短语保留、章节配额和相邻段落扩展；支持指定章节范围，向量服务失败时继续使用本机检索。
- 原文相关性重排：独立服务商与模型、保留手动选中的原文、同步引用编号，服务失败时继续使用原检索顺序。
- 书库伴读的书架整理预览：批量添加或移除标签、移入一级分组；手动确认后一次应用，方案及处理结果随本地备份保存。
- 完整本地备份、恢复前校验、恢复内容预览和撤销上次恢复。
- 按书查看存储占用，清理正文后保留阅读记录、笔记和伴读话题。

书籍和对话保存在设备中，服务商密钥保存在系统钥匙串。发送伴读消息时，所选服务商会收到角色资料、近期对话和检索到的已读原文。角色设定不能保证模型绝不剧透；原文检索按本地阅读边界截断。向量记忆在「设置 → 向量记忆」中单独选择 OpenAI 兼容或 Gemini 服务商及向量模型，按书开启后，会将已读片段与检索问题发送给该服务商。索引保存在本机，可停止整理、单独清理，并随完整备份恢复。

原文检索先按已读范围取正文片段，再以 BM25 词项相关性和向量排名进行加权 RRF 融合；短查询增加词项权重，并为精确命中的人名、短语保留结果。重排在结果配额与相邻段落扩展之前进行，按同一章最多 2 段、名额未满时放宽到 3 段选择候选，再合并相邻窗口。检索工具可指定起止章节、结果数量及章节或相关性顺序。一次本机扫描最多覆盖 20000 章、2000 万个 UTF-16 单位；读取失败或达到上限时显示覆盖不足提示。全局伴读只查询已存在的向量索引，模型不匹配时保留原索引并回退到词项检索。检索结果用于核对原文，不代表完整统计或事实成立概率。

「设置 → 原文相关性排序」可配置 Cohere / Jina 兼容的重排服务商、模型与接口路径，默认关闭。开启后，把检索到的已读原文按与问题的相关程度重新排序；每次最多 24 段、每段 800 个 UTF-16 单位、合计 12000，问题最多 512。请求超时为 5 秒；失败时保留原顺序，并在回复中显示提示。重排会将这些片段与问题发送到所选服务商并按其规则计费。接口格式参考 [Cohere](https://docs.cohere.com/v1/reference/rerank) 与 [Jina](https://jina.ai/api-dashboard/?model=jina-reranker-v1-turbo-en)。

「设置 → 伴读工具」可开关主动查询，并为每个角色选择可用工具；需要当前聊天模型支持工具调用。单书伴读查询当前书籍，全局伴读可按书名或作者查找书籍，再使用返回的编号查询内容。原文按发送消息时的已读边界截断；每次最多读取 5 章，单书最多 24000 个 UTF-16 单位、全局最多 6000，可按返回的偏移继续读取。一次回复最多进行 8 轮查询、每轮最多 8 项，最多主动查阅 4 本书。结果发送给当前聊天服务商，可能产生多次模型调用费用。回复下方的“查询过程”保留各步结果，原文引用可以展开核对；停止回复也会停止后续查询。

在「伴读 → 开启新话题」中可请角色整理书库。角色先查询真实书名、编号、分组和标签，再生成待确认方案；每份最多 20 本，每本最多添加 8 个、移除 8 个标签，也可移入已有或新建的一级分组。聊天中的“查看整理方案”展示调整前后的内容；点击“确认应用到书架”才会保存，或选择“取消这份方案”。确认时重新检查书籍、原分组及标签，发生变化的旧方案会拒绝应用。分类修改与处理记录写入同一个文件，重复确认会被拦截；重启、分支话题和备份恢复后仍保留处理结果。该工具可在角色的“可用工具”中关闭。

在一本书的伴读中，可以请角色添加原文批注、保存独立笔记或整理剧情梗概。批注必须逐字匹配已读原文；重复引文需要来源编号或更完整的引文来定位。笔记保存角色署名和来源范围，角色只能更新自己创建、尚未被用户编辑的同类内容；梗概默认滚动更新当前角色最新一篇，也可另存新篇。标题最多 120 字、正文最多 50000 个 UTF-16 单位。阅读页「批注 → 读书笔记与梗概」可以查看、搜索、筛选、编辑、新建和删除，亦可导出 Markdown；清理正文后，笔记仍可从「设置 → 存储与阅读记录」查看。

角色长期记忆在「设置 → 长期记忆」开启，默认关闭。选择记忆整理服务商，并配置向量服务商与模型后，对话达到整理门槛会在后台提炼；角色资料与聊天的记忆面板可以查看、修改和遗忘。整理会将对话、候选记忆与相关旧记忆发送给整理服务商，向量服务商会收到记忆文本和检索问题。记录保存在本机并纳入完整备份；阅读时可单独允许跨书回忆，涉及书籍的记忆仍会校验已读范围和原文版本。

主题色在「设置 → 主题与外观」更改。阅读时打开「排版」，可选择翻页方式、进入沉浸阅读，或通过「阅读背景图片」选择照片并调整浓度；纸张选“自定义颜色”或“背景图片”时，可分别选择背景底色与正文颜色。

阅读页「书签 → 添加当前位置书签」保存当前段落，保存后显示确认提示；点击列表中的书签返回原处。「伴读 → 角色与世界书 → 编辑」可更换头像；进入「世界书」导入独立 JSON 或新建设定，返回角色资料点击“保存”。导入兼容 `entries` 数组和 SillyTavern 条目字典，追加到现有设定。

「设置 → 随读段评」可开启自动评论，默认关闭。开启后，阅读器会将已读章节中的目标段落、截至该段的正文前缀和相关前文发送到所选服务商。评论保存到「批注」，与自己的笔记分开标注作者；离开阅读页、切到后台或点击停止会取消本次任务。每章和每日额度由参与角色共享，可在设置中调整。

自选字体从「设置 → 字体库」或阅读页的「排版 → 字体与段落 → 管理与导入字体」导入，单个文件上限 64 MB，也可以从其他应用分享打开。导入后设为正文字体；EPUB 关闭“保留原书排版”后应用。删除正在使用的字体会恢复内置字体。

云端声音在「设置 → 云端声音与缓存」中配置。开启后，朗读片段会发送给所选语音服务商，并按其规则计费；已生成音频保存在本机，纳入完整备份。缓存达到设置上限时，先清理最久没有播放的音频。

## 开发

双击 `MoRead.xcodeproj`，在 Xcode 中打开工程并等待组件下载完成。顶部选择 `MoRead` 和一个 iPhone 模拟器，再点击三角形运行按钮。

安装到自己的 iPhone：

1. 在 Mac 打开 Xcode，完成首次启动设置，并在 Xcode 的 Settings → Accounts 中登录 Apple 账户。
2. 用数据线连接 iPhone，按手机提示信任这台 Mac。
3. 在工程左侧点击蓝色 `MoRead` 图标，选择 TARGETS 下的 `MoRead`，打开 Signing & Capabilities，在 Team 中选择自己的账户。
4. 在 Xcode 顶部设备列表选择这台 iPhone，点击三角形运行按钮。若手机要求启用“开发者模式”，按设备提示完成后再运行。

核心检查使用 `swift test`。`project.yml` 是工程配置，修改它后用 XcodeGen 执行 `xcodegen generate`。GitHub Actions 会构建 iPhone 应用，并在模拟器中检查 TXT 与 EPUB 阅读及重启后的进度恢复。语音接口检查使用固定响应样本，模拟器用本地测试音频验证播放、暂停、跳章和章节定时。角色长期记忆的模拟器检查使用本地固定回复，验证整理、编辑、调用、遗忘和重启保存。混合检索检查覆盖中文词项、距离过滤、章节配额、相邻原文、防剧透与缺章提示；模拟器使用本地候选验证引用和向量服务故障后的回退。相关性排序检查使用本地固定排序和故障响应，验证实际伴读来源顺序与回退。查询工具检查使用四种接口的流式响应样本，验证调用续接、签名保留、限额与取消；模拟器使用本地查询请求检查目录、引文、未读章节拦截和重启后的记录。写入检查覆盖引文消歧、角色归属、已读范围、梗概更新、备份恢复，以及模拟器中手动编辑后阻止角色覆盖。书架整理检查覆盖方案校验、整批应用、过期拦截、重复处理和备份恢复；模拟器验证预览不修改书架、确认后分组生效、取消及重启保存。真实服务商连接及真机锁屏播放需另行验收。云端产物未经个人账户签名，不能直接安装到手机。
