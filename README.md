# 墨知 MoRead · iOS

面向 iPhone 和 iPad 的本地阅读器，基于 [MoRead](https://github.com/ovo066/MoRead) 的功能与数据规则移植。

当前为开发中的版本。可复用核心包含 TXT 编码读取、章节识别、书籍与阅读记录存储、原文引用校验和已读范围搜索。

## 开发

核心使用 Swift Package，可在安装完整 Xcode 的 Mac 上运行 `swift test`。
